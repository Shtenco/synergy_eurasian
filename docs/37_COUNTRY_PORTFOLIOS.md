# 37 — Country Portfolios: пять стран как динамическая сеть, не фиксированное разделение труда

## Правило

Ниже — **стартовые portfolio hypotheses** для EIIOM-v4. Это не официальная политика стран и не вечная специализация. После загрузки реальных spatial data модель должна иметь право перераспределить проекты.

---

# Россия — Industrial Scale / Energy / Engineering Core

## Сильные роли для проверки

### R1. Power / grid / nuclear-industrial competence

- generation upgrades;
- grid equipment;
- industrial heat;
- transformer/power-electronics chains;
- high-reliability power for industry/compute.

### R2. Heavy machinery / machine tools / robotics

- modernization existing plants;
- machine-tool ecosystem;
- robotics for metallurgy/mining/logistics;
- high-duty industrial components.

### R3. Industrial AI

Highest leverage may come from improving a very large installed industrial base rather than building everything greenfield.

```text
legacy plant
→ sensors/data
→ digital twin
→ AI/process control
→ automation
→ measured productivity gain
```

### R4. Materials

- steel/alloys;
- electrical steel;
- copper downstream;
- specialty materials;
- industrial ceramics/composites where economics close.

### R5. Large scientific/compute nodes

Only with contracted power and workload, and with hardware supply/obsolescence scenarios.

### R6. Agriculture scale

- grain/oilseed/forage;
- seed trials;
- autonomous large machinery;
- processing/export.

### R7. Renovation / industrial cities

Large opportunity to connect housing modernization with labor retention and industrial productivity.

## Risk concentration

- imported technology/components;
- external market/legal access;
- long CAPEX cycles;
- regional inequality;
- grid bottlenecks despite aggregate generation;
- high cost of building prestige tech without demand.

## Suggested first project families

1. transformer/power-electronics bottleneck program;
2. industrial AI gain-share program;
3. machine-tool modernization clusters;
4. energy-efficiency retrofits;
5. agro processing/export nodes;
6. selective grid-backed inference/HPC sites;
7. renovation pilots linked to industrial labor retention.

# Казахстан — Materials / Steppe Agro / Logistics / Compute Bridge

## K1. Materials downstream

Move from resource advantage toward:

```text
extraction
→ refining
→ qualified material
→ cable/component/equipment supply
```

especially where downstream EAEU demand is visible.

## K2. Uranium / civilian nuclear value chain

Only legally eligible civilian downstream steps and industrial cooperation.

## K3. Dryland AI agriculture

Priority research areas:

- drought/salinity genetics;
- wheat/oilseed;
- field-scale precision agriculture;
- satellite/drone sensing;
- autonomous machinery;
- water optimization;
- storage/processing.

## K4. Logistics hub

Kazakhstan sits across major east-west and north-south Eurasian flows. EIIOM should model:

- rail bottlenecks;
- dry ports;
- warehouses;
- cold chain;
- border dwell time;
- Middle Corridor and northern/southern alternatives.

## K5. Data/compute

Potential role:

- power-backed regional compute;
- inference/cloud for Central Asia;
- industrial/agro AI;
- disaster-recovery/secondary sites.

But power, grid, hardware and customers must all exist before CAPEX.

## K6. Water infrastructure

Critical under climate stress:

- irrigation efficiency;
- basin measurement;
- reuse;
- leak reduction;
- crop-water optimization.

## K7. Rural AI clusters

Kazakhstan is a natural testbed for large-area distributed clusters, but settlement design must solve distance, healthcare, schools, transport and jobs—not only agriculture.

## Risks

- water;
- long distances;
- logistics border friction;
- concentration in commodities;
- grid constraints;
- imported equipment;
- rural human-capital retention.

## First project families

1. precision-ag + shared autonomous fleet;
2. seed/drought trial network;
3. irrigation modernization;
4. grain/oilseed deep-processing;
5. warehouse/dry-port/cold-chain nodes;
6. copper/material downstream projects with offtake;
7. grid-backed compute only with anchor workload.

# Беларусь — Machine / Robotics / Agro-Industrial Production Hub

## B1. Machine-building upgrade

Use installed engineering base for:

- machine tools;
- agricultural machinery;
- industrial equipment;
- robot integration;
- power electronics/control.

## B2. Physical AI

Combine:

```text
machine building
+ sensors
+ computer vision
+ industrial AI
+ autonomous control
```

## B3. Agro machinery / service fleets

Exportable solutions for RU/KZ/KG/AM farms if reliability and TCO beat alternatives.

## B4. Food / agro processing

- dairy;
- potato/forage/flax-associated chains;
- cold chain;
- packaging;
- high-value processing.

## B5. Seed/nursery / field automation

Strong candidate for tightly instrumented high-productivity farms and trial nodes.

## B6. Industrial retrofit export

Instead of only selling new machines, export full productivity package:

```text
audit → retrofit → automation → AI → service contract
```

## Risks

- market access;
- scale of domestic demand;
- imported electronics/components;
- aging equipment/skills;
- financing access.

## First project families

1. robotic machine-tool cells;
2. agro-robotics service/export;
3. industrial retrofit ESCO/gain-share;
4. food-processing modernization;
5. power-electronics/control localization;
6. compact industrial AI cloud/inference.

# Армения — Algorithm / Design / High-Value R&D / Specialty Agriculture

## A1. AI/software/math

Focus on high-value, low-physical-logistics products:

- AI models;
- optimization;
- simulation;
- cybersecurity;
- EDA/design;
- industrial software.

## A2. Semiconductor design / IP

Prioritize:

```text
design / verification / firmware / IP
```

before capital-intensive fabrication.

## A3. Science commercialization

Use compact high-skill ecosystem for:

- prototyping;
- algorithmic R&D;
- university spinouts;
- cross-EAEU engineering teams.

## A4. High-value agriculture

- horticulture;
- viticulture;
- high-value nursery/seedlings;
- microclimate AI;
- water efficiency;
- specialty processing/export.

## A5. Regional innovation services

Engineering/AI design exported to industrial projects in RU/KZ/BY/KG.

## Risks

- small domestic scale;
- connectivity/logistics;
- talent migration;
- energy/resource constraints;
- project concentration.

## First project families

1. EDA/domain accelerator design labs;
2. industrial AI/software export teams;
3. agrigenomics/high-value crop labs;
4. cybersecurity/PQ engineering;
5. prototype-to-EAEU-manufacturing pipeline.

# Кыргызстан — Hydro / Water / Mountain Agro / Connectivity Node

## G1. Hydro and water systems

Value is not only generation; optimize joint:

```text
hydro + irrigation + reliability + seasonal water constraints
```

## G2. Mountain agriculture

- fruit;
- forage;
- specialty crops;
- nursery;
- dairy;
- water-efficient farming.

## G3. Food processing

Small/medium exportable high-value processing can dominate raw commodity shipment economics.

## G4. Edge AI / distributed digital services

Use edge compute for agriculture, logistics, public services and remote education/health where infrastructure exists.

## G5. New connectivity

Transport projects connecting the country to broader Central Asian corridors can materially change project economics. EIIOM should treat future corridor openings as scenarios, not already existing capacity.

## G6. Rural clusters / remote-work nodes

Smaller distributed settlements with digital connectivity can combine agriculture, tourism, services and remote work.

## Risks

- financing capacity;
- mountainous logistics;
- grid/transmission;
- water seasonality;
- small local market;
- migration of skilled labor.

## First project families

1. water/hydro optimization;
2. fruit/dairy cold chain;
3. high-value processing;
4. edge-agro services;
5. logistics nodes tied to actual corridor commissioning;
6. skill/remote-work rural clusters.

# Cross-country value chains

## X1 — Copper → Power Equipment → Grid → Compute/Industry

```text
KZ/RU feedstock/refining
→ BY/RU equipment manufacturing
→ EAEU grid/DC/factories
→ external exports
```

Actual locations determined by delivered cost and qualification.

## X2 — Seed Intelligence → Machinery → Food Export

```text
AM/RU/KZ/BY/KG research/trials
→ seed multiplication where agronomically optimal
→ BY/RU/KZ machinery/robotics
→ farms across EAEU
→ processing nodes
→ Eurasian corridors
→ external markets
```

## X3 — AI Design → Industrial Deployment

```text
AM/RU/BY/KZ AI teams
→ common model/evidence contracts
→ industrial sites RU/BY/KZ/KG/AM
→ measured productivity
```

## X4 — Machine Tools → Robotics → Renovation / Industry

```text
BY/RU machine capability
→ power electronics/components across network
→ automation
→ construction/industrial/agro projects in all states
```

## X5 — Transport → Export

Production location must be selected together with corridor and destination market, not before them.

# Country score must be endogenous

Replace fixed suitability with:

```text
Suitability[c,s,t,ω] = f(
  delivered_power_cost,
  grid_headroom,
  logistics,
  labor_skill,
  wage_productivity,
  water,
  installed_supplier_base,
  financing,
  market_access,
  policy/legal state,
  risk
)
```

Thus specialization evolves as investment changes the underlying state.

# Final principle

> **Five countries are not five departments of one planner. They are five sovereign economies connected by projects whose cooperation must win economically, physically and institutionally against realistic alternatives.**
