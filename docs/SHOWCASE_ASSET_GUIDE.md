# SYNERGY EURASIAN — руководство по визуальной документации

Этот репозиторий содержит **12 оригинальных масштабируемых SVG-иллюстраций** в `assets/readme/`. Схемы созданы для технической документации без внешних зависимостей, фотостоков и недостоверных визуализаций производственных объектов.

## Что является фактом, что сценарием

- `hero.svg` — концептуальная фирменная обложка, не фотография развернутых систем.
- `economy-loop.svg`, `eiiom-compiler.svg`, `federation.svg`, `capital-flywheel.svg` — архитектурные схемы. Не доказывают работающий end-to-end runtime.
- `base-v2-scenario.svg` — визуализация **только** референсного LP-сценария из `data/base_v2_reference_summary.json`, а не фактического привлечённого капитала, ВВП или прибыли.
- `project-factory.svg` — целевая структура воронки из `docs/29_PROJECT_FACTORY_1000.md`, не реальные 1000 обработанных проектов.
- `five-countries.svg`, `seven-superchains.svg`, `roadmap.svg`, `safeguards.svg`, `control-tower.svg` — гипотезы, методология и контрольные требования.

## Обслуживание

При изменении `data/base_v2_reference_summary.json` обновляйте цифры в `base-v2-scenario.svg` и README одновременно. После обновления запустите `python scripts/check_readme_media.py`.

## Авторское право

Оригинальная графика входит в состав проекта; применяются уведомления и ограничения из корневого `LICENSE`. Сторонние шрифты и фотографии в SVG не встроены.
