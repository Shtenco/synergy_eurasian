# 14 — Crowd-Investment Case Studies: Positioning & Investor Interaction Only

## Scope

Этот документ **не предлагает использовать технологии** Torus, SkyWay/uST, Sovelmash или двигатели Дуюнова в SYNERGY.

Технологическое ядро СИНЕРГИИ — собственное. Здесь изучаются только:

- позиционирование;
- investor onboarding;
- low-ticket entry;
- installment/commitment mechanics;
- personal cabinet;
- roadmap communication;
- community;
- offline/online events;
- partner/status systems;
- retention;
- storytelling around physical progress.

## 1. Torus — сильная идея «распределённого капитала»

Полезное наблюдение: участнику психологически интереснее роль **совладельца/созидателя экосистемы**, чем роль пассивного покупателя неизвестного финансового продукта.

Что переносим как UX:

- ощущение участия в реальном бизнесе;
- несколько взаимосвязанных бизнес-направлений;
- community identity;
- возможность приносить капитал, компетенции, поставщиков и клиентов;
- демонстрация реального сектора;
- статус участника как части большой системы.

Что не переносим:

- непрозрачный общий «котёл»;
- гарантии будущей доходности;
- artificial scarcity / urgency;
- схемы, где выплаты могут зависеть от постоянного нового притока.

## 2. SWC / SkyWay — long-horizon mission & community

Полезные механики:

- большая миссия на десятилетия;
- постоянное ощущение движения проекта;
- экскурсии/демонстрационные площадки;
- личный кабинет;
- международные сообщества;
- регулярный контент;
- понятный narrative «я участвую в будущем».

Для SYNERGY правильная версия:

```text
mission
+ transparent project SPV
+ independent evidence
+ legally defined investor rights
+ no guaranteed return
```

## 3. SOLARGROUP — investment UX engine

Особенно полезны как продуктовые паттерны:

- маленький первый платёж/низкий психологический порог;
- регулярный payment/commitment plan;
- portfolio dashboard;
- project roadmap;
- регулярные webinars/news;
- regional meetings;
- partner statuses;
- local-language support;
- visible construction/production progress;
- certificates/documents/physical sense of participation.

### Что меняем принципиально

У SYNERGY monthly plan — это **saving commitment**, а не долг перед платформой.

```text
IncomeShock → pause/reduce contribution
Penalty = 0
```

Партнёрская система вознаграждает **экономическую ценность**, а не сумму привлечённых инвестиций.

```text
GOOD:
  customer introduced
  supplier qualified
  engineer recruited
  export contract sourced
  cost saving verified
  useful code/data contribution

BAD:
  reward = percentage of recruited investor deposit
```

## 4. Почему нужна осторожность

При изучении этих проектов важно разделять:

```text
Engineering/operating asset
!=
Investment/legal wrapper
```

Внешняя технология может быть физически реальной, но это не доказывает качество инвестиционной схемы.

Перед публичным сравнением или использованием конкретных формулировок всегда проверять актуальные официальные warning lists/регуляторные статусы.

Официальная точка проверки в РФ:

- https://www.cbr.ru/inside/warning-list/

## 5. SYNERGY synthesis

Берём лучшие **поведенческие** элементы:

```text
Torus:
  distributed capital + co-owner identity

SWC:
  long-horizon mission + visible future

SOLARGROUP:
  onboarding + commitment plan + cabinet + community + frequent updates
```

Добавляем собственные защитные слои:

```text
AI-CFO / Delta
+ emergency-reserve-first
+ regulated project instruments
+ separate SPV
+ ProjectProposal
+ EvidencePackage
+ transparent NAV/accounting
+ anti-double-collateral rules
+ no MLM investment rewards
+ no guaranteed returns
+ human/regulatory gates
```

```text
  ↓

  ↓
Creator / Partner path
```

## 7. Core positioning

> **СИНЕРГИЯ — система народного капитала.**

> **Миллионы маленьких Дельт — один большой производительный капитал.**

> **Объединяем капитал — создаём будущее.**

При этом public mission и investment disclosure всегда разделены визуально и юридически.
