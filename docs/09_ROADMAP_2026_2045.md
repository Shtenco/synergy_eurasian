# 09 — Roadmap 2026–2045

## Принцип

Не строить «всю Евразию сразу». Каждая следующая фаза открывается только после доказательства экономики предыдущей.

## Phase 0 — 2026: Architecture & Baseline

Цель: сделать репозиторий и данные пригодными для реального underwriting.

Deliverables:

- canonical Real Economy OS architecture;
- ProjectProposal / EvidencePackage schemas;
- reproducible EIIOM solver;
- baseline data registry;
- sector coefficient registry with sources/status;
- hard accounting/risk invariants;
- first 10–20 project archetypes;
- dashboard specification;
- data/API contract with Financial OS;
- independent review methodology.

Exit gate:

```text
CI green
Conservation tests green
At least 3 project archetypes reproduced end-to-end
No modelled GVA booked as cash
```

## Phase 1 — 2026–2030: Demonstration Network

Scenario CAPEX envelope: **$120bn gross across all sources**.

Цели:

- первые industrial AI deployments;
- ~0.4 GW incremental modeled AI IT-load;
- grid/power-electronics capacity ahead of compute;
- common industrial data schema;
- seed/genomics data foundation;
- ~30 rural AI clusters;
- ~12m m² urban-renovation target;
- ~3m m² rural swing housing target;
- ~13m ha precision-ag target;
- first regulated project-CFA/RWA pilots;
- Productive Escrow only as regulator-approved limited pilot outside this repository.

Exit gate:

- measured industrial AI payback;
- anchor demand for compute;
- functioning evidence pipeline;
- housing voluntary/return-right audits;
- seed/agro physical trial results;
- no solvency/accounting invariant breach.

## Phase 2 — 2031–2040: Scale

Scenario incremental CAPEX envelope: **$290bn**.

Цели:

- ~1.2 GW modeled cumulative IT-load;
- mass industrial AI + digital twins;
- robotics/machine-tools scale;
- power-electronics localization;
- common technical certification;
- 100 rural AI clusters;
- ~65m m² cumulative renovation target;
- ~47m ha precision agriculture;
- ~14.5m ha agro-robotics;
- expanded project-finance market;
- retail participation only through compliant suitability-gated instruments;
- institutional/pension/infrastructure capital grows relative to retail.

Exit gate:

```text
Industrial utilization healthy
Default/loss ratios within policy
External cashflow grows faster than internal claims
Escrow outstanding remains bounded
No country > policy concentration limit in critical infrastructure
```

## Phase 3 — 2041–2045: Autonomous Industrial Network

Scenario incremental CAPEX envelope: **$240bn**.

Цели:

- ~1.5 GW modeled AI IT-load in BASE-v2 (subject to hardware economics);
- 160 rural AI clusters;
- 100m m² urban renovation target;
- 60m ha precision agriculture;
- 15m ha deep agro-robotics;
- large-scale autonomous industrial operations;
- cross-country input-output optimization;
- export of technology, equipment, software, seeds and processed goods;
- larger share of CAPEX funded by reinvested system cashflow rather than anchor public capital.

## Financing trajectory

Вместо единого $650bn funding round:

```text
$10–20bn anchor NAV
  ↓
project equity + debt + CFA/RWA + offtake
  ↓
$50–80bn first productive asset base
  ↓
operating cashflow / reinvestment
  ↓
$150–200bn scaled asset base
  ↓
20-year cumulative gross CAPEX ≈ $650bn scenario
```

Это illustrative flywheel, не гарантированный leverage path.

## Technology build order

### First priority

1. grid / substations / power electronics;
2. industrial data + AI deployments with measurable savings;
3. materials/refining tied to offtake;
4. seed/genomics + precision-ag pilots;
5. machine tools / robotics for existing installed base;
6. evidence/accounting infrastructure.

### Second priority

7. AI-ready DC shell only with hardware + power + customers;
8. scaled accelerator compute;
9. rural AI clusters;
10. food processing / cold chain;
11. renovation in cities with tested swing-housing mechanics.

### Avoid premature megaprojects

- universal leading-edge semiconductor fab without economics;
- huge empty data centers;
- raw mining without downstream demand;
- speculative housing detached from residents/jobs;
- token issuance presented as productive output;
- unbounded common QE;
- bridges treated as sources of wealth.
